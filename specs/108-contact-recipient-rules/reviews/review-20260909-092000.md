## The sharpest one, stated once

> **Round 1 closed S5 with an arm that matches a kind the resolver never produces.**

`resolve-segment-recipients.ts:422` returns `err({kind:'broadcast_empty_segment_blocked'})`.
`broadcasts-deps.ts:942` passes it through raw (`return err(resolved.error)`).
`build-audience-tick.ts:762` matches **`broadcast_audience_post_suppression_empty`** — a kind
produced only by the legacy `dispatch-scheduled-broadcast.ts:485`.

So `mapResolveError` falls to `dispatch.server_error`, the cron buckets it `retryable`, and an
approved broadcast whose audience emptied stays `approved` and is re-claimed every five minutes
for ever — with no terminal state, no audit row and no member email. **That is verbatim the
defect `onResolveFailure`'s own docblock says it exists to remove.** It was removed for
`too_large` only.

Two things made it invisible:

1. `ResolveAudienceError` carries a `| { readonly kind: string }` member (`build-audience-tick.ts:166`),
   so comparing against an impossible literal **typechecks**.
2. Every unit test stubs `resolveRecipients` with the phantom kind — so the suite exercises dead
   code and passes green.

The lesson is not "check your string literals". It is that **a union with an open `string` member
cannot enumerate its own arms**, and once that escape hatch exists the compiler stops being the
thing that finds this class. Same shape as the `return _exhaustive` family already in this repo's
memory.

## What this round says about the last two

Round 1 found 56, round 2 found that round 1's fixes introduced 5 defects, and round 3 — cold, no
knowledge of either — found **8 more that neither had seen**, including a red test and a
never-transmitted idempotency key.

The pattern across all three is one thing: **every defect that survived was one where a comment,
a docblock, or a test asserted the behaviour instead of the code providing it.** 3-1's comment says
the SDK accepts the key. 3-2's docblock says the refusal is terminal. 3-9's runbook says the drain
is safe. 3-11's header says "CORRECTED". The tests that should have caught 3-2 stubbed the phantom
kind and went green.

**So the rule this round adds to the two already in `README.md`: a claim in prose is not covered by
a green suite. Grep the assertion, not the sentence.**
