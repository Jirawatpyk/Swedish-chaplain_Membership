# Contract: CSS layer order and imports (the token bridge was removed at US13b)

## Head of `src/app/globals.css`

```css
@layer aura-tokens, theme, base, aura, components, utilities;
@import 'tailwindcss';
@import '@jirawatpyk/aura-tokens/aura.css' layer(aura-tokens);
@import '@jirawatpyk/aura-tokens/aura-fonts.local.css';
@import '@jirawatpyk/aura-tokens/tailwind.prefixed.css';
@import '../styles/aura-theme.css' layer(aura-tokens);
@import '@jirawatpyk/aura-react/styles.layer.css';
```

`aura-theme.css` is generated by `aura-theme` and never edited by hand. Since AURA 5.31 it also carries the checked-control colour (`--aura-control-checked-bg/-fg`, #139), so the US8c-1 hand-written `aura-overrides.css` is gone (US8c-2).

`@custom-variant dark (&:is(.dark *));` stays. AURA reads `.dark` on `<html>`, which next-themes already sets.

## Token bridge — removed (US13b)

Until US13b, `:root` aliased every legacy shadcn variable (`--background`, `--muted-foreground`, `--primary`, `--border`, `--ring`, `--chart-*`, `--sidebar-*`, `--radius`, …) to an `--aura-*` token, so pages not yet on AURA took its palette. With the kit gone (US13a) the bridge, `tw-animate-css` and `shadcn/tailwind.css` went too:

- `globals.css` defines no shadcn variable; `@theme inline` holds the fonts above, the TSCC gold (`--color-brand-accent*`) and two entrance animations (`--animate-chamber-fade-in`, `--animate-chamber-zoom-in`).
- Code names AURA tokens directly: `text-[var(--aura-fg-secondary)]`, `text-[var(--aura-fg-danger)]`, `rounded-[var(--aura-radius-sm)]`.
- `@layer base` gives a bare `border` `--aura-border-default`, the focus outline `--aura-focus-ring`, and `body` `--aura-bg-canvas` / `--aura-fg-primary`.
- The `data-open:` / `data-checked:` / `data-active:` … variants and `no-scrollbar` that `shadcn/tailwind.css` defined went with it. Tailwind's built-in `data-*:` variants match differently (`[data-active]` also matches `="false"`, and they carry specificity), so they are banned rather than silently reused.
- **Guards:** `tests/unit/styles/aura-foundation-css.test.ts` (the import list, no bridge name defined) and `tests/unit/architecture/no-bridge-colours.test.ts` (no shadcn class, `var()`, theme radius or tw-animate utility in `src/`).

## Z-index

- AURA owns its overlay stacking (`--aura-z-menu`, `--aura-z-dialog`, `--aura-z-toast`, `--aura-z-tooltip`); the kit's z-index mapping went with the kit (US13a).
